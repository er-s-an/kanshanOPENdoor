# 看山任意门：玩家完整流程基线 v1.0

> 状态：2026-09-14 流程定案，并同步到 `main@dc8bed6` 的本地集成快照。本文区分“本地已实现”和“验收完成”；当前版本尚未完成最终新存档 Ego 全流程与公网验收，不能据此宣称全链路已经发布。
>
> 本文只锁定玩家看见并完成的顺序，不规定目标游玩时长。玩家可以慢慢读、自由追问和继续探索；流程只按已完成的行为与证据状态推进。

## 1. 一句话体验

玩家推开一扇通往盐言故事的门，在刘看山带领下亲历异常、向人物追问、在现场寻找并核对证据，最后回到知乎式公共讨论中提出一条自己愿意负责的判断，并获得一张由本局真实选择生成的调查人格卡。

这不是严格 TINAG 的 ARG，也不是把每个页面都伪装成知乎。准确形态是：

**刘看山任意门 × 沉浸式故事现场 × 知乎原生伪界面悬疑。**

知乎页面承担信息发现、人物连接、公共论证和分享回流；故事现场承担亲历、行动和物证调查。两者在同一案件中往返，不互相冒充。

## 2. 入口原则

### 默认入口

- 公网首页首先进入刘看山接站页，不默认进入任何故事，也不在加载完成后自动替玩家选门。
- 刘看山用三句话以内说明“这里是什么、玩家可以做什么、下一步是自己选一扇门”，唯一主按钮是**“去选一扇门”**。
- 玩家确认后才展示故事库；旗舰《蓝血》可以置顶和重点呈现，但必须由玩家亲手点击进入。
- 带 `?story=` 的活动链接、人格卡链接和知乎内容入口只预选并突出对应故事，仍由刘看山接站、玩家确认；只有内部评审用 `?scene=` 暗门可以跳过。

### 返回玩家

- 有存档时，门上显示“继续上次调查”；旁边提供较弱的“从头开始”。
- 自动保存每个完成的选择、取得的证据、对话话题和 Boss 进度。
- 不用登录也能完成、保存和生成基础人格卡。

### OAuth 出现位置

- OAuth 永远不是入场门槛。
- 玩家已经完成一段体验后，才可在分享或个性化区域选择登录。
- 真实关注答主不被编造为剧情发言者。未取得对方授权时，只能展示真实公开内容入口或“你关注的相关创作者”，不能替真人写虚构证词。

## 3. 刘看山的统一角色

刘看山在技术上承担系统引导，但在玩家眼中必须是一个会出现、会说话、会开门的**引路狐**，不是冷冰冰的系统通知。

他只知道玩法状态，不知道原作尚未公开的真相：

- 入场：说明玩家是谁、眼下发生了什么、第一步能做什么。
- 转场：开门进入现场还原，或把玩家带回帖子/私信。
- 卡关：指出下一类可行动方向，不直接说答案。
- 错误：解释为什么这个动作没有推进，而不是只说“错了”。
- 结局：主持复盘和调查人格揭晓。

首次引导最多三句话，并在真实界面中完成第一次操作，不做长教程弹窗：

1. “我是刘看山，负责把你送进这段记录。”
2. “先别急着猜幕后。看到不对劲的地方，就把它留下来。”
3. “你决定相信什么、追到哪里、要不要说出去，都会留在最后那张卡上。”

玩家做完第一个有效动作后，引导自动收起；后续只在需要时出现。

## 4. 一条完整玩家旅程

### 0. 网站接站与故事门：先认识引路人，再产生进入欲望

**玩家看到**：先是刘看山的完整接站画面与短对白；确认后才看到多扇故事门、故事钩子与各自明确的进入按钮。

**玩家做**：先点“去选一扇门”，再阅读故事门并亲手选择；若有存档则选择继续或重来。

**完成条件**：故事配置和首屏关键素材加载成功；失败时仍可用文字入口进入。

**当前状态**：根路径已拆成“刘看山接站 → 玩家选门 → 刘看山开门”三个状态；普通 `?story=` 不再自动进故事，评审 `?scene=` 暗门保留。

### 1. 刘看山开场：知道自己为什么行动

**玩家看到**：刘看山从门边出现，以故事内容为背景给出三句以内的任务简报。

**玩家做**：完成一个真实操作，例如点开第一条异常记录、标记一句矛盾或回应一个角色。

**完成条件**：玩家能回答“我是谁、我现在为什么行动、下一步能做什么”。

**兜底**：可跳过；跳过后在当前行动旁保留一句短提示。

**当前状态**：已实现。新存档在开门后、第一幕前进入刘看山故事简报，用“你的身份 / 这里不对劲 / 先做这件事”三句话说明任务；可跳过、可换门，旧存档继续时不会重复拦截。

### 2. 处境发生：先体验异常，不先看工具说明

**玩家看到**：原作范围内的事件与人物反应，场景图服务于当前处境。

**玩家做**：阅读、回应一次必经抉择，形成最初立场。

**完成条件**：异常已经发生，玩家自然产生一个需要验证的问题。

**设计规则**：故事原文先制造问题，工具随后出现；不能一入场就把线索板、百分比和所有热点同时亮出来。

**当前状态**：《蓝血》多幕叙事与场景图已接入；刘看山故事简报已经放在新局第一幕之前，第一步直接指向真实场景动作。最终连续实玩仍随整条玩家旅程一起验收。

### 3. 知乎信息层：找对问题，也找对人

**玩家看到**：与剧情时序一致的帖子/回答、评论楼、编辑痕迹和人物入口。它是剧情中的社区页面，不是脱离原作的通用假首页。

**玩家做**：

- 从正文或评论中标记一个值得核对的词句；
- 在“先查材料”与“先问相关人物”之间作出一次必经选择；
- 回复或进入一位相关人物的私信。

**完成条件**：得到一个明确调查方向，并解锁私信或现场还原入口。玩家不需要翻完所有评论。

**体量规则**：首屏与正常滚动范围内约 18–30 条可读评论，3–5 个有剧情作用的账号；其余体量用折叠楼和计数营造，不用 80–150 条噪声拖慢玩家。每一屏至少有一个可理解的有效信息或行动入口。

**错误兜底**：回复无关账号也得到一句符合人设的回应；刘看山说明“这个人只知道什么”，同时缩小范围，不扣资源、不重置。

**当前状态**：已实现《蓝血》首个可玩 `post` 社区段落：1 个含 14 条回应的帖子流、4 个可追查账号及各自的评论/私信详情页。账号身份、知情边界、气氛楼与可行动楼层分开；玩家至少核对一人后才可离开，选错账号不会授证或进入死路。其它故事尚未要求复制同等体量。

### 4. 私信追问：把人证问出来

**玩家看到**：人物头像、已发生的对话、2–3 个可发现的询问方向、自由输入和“出示记录”。

**玩家做**：使用快捷话题或自由措辞追问；必要时出示已经取得的一条记录。

**完成条件**：至少得到一条规范证言或确认对方不知道什么；无需问完所有话题。

**状态反馈**：NPC 的信任/戒备影响接下来几轮的措辞和自愿程度，但不改写硬事实，也不锁死主线。

**故障兜底**：LLM 超时、拒答或离线时使用预写回应；关键证言仍由话题契约授予。

**当前状态**：快捷话题、自由输入、白名单授证和离线回退已有；桌面无消息的卡死问题需要以完整路径重新验收，NPC 情绪黏性尚未实现。

### 5. 现场还原：真正搜证，而不是把房间点一遍

**玩家看到**：刘看山开门后进入当事人视角的现场。默认不显示满屏发光点。

**玩家做**：围绕当前问题选择观察方式，点击有语义的区域或输入具体搜索词；发现后打开一张可读、可复制、可放上证据板的纸质记录。

**完成条件**：取得当前问题所需的一条基础证据，并完成一次“这能证明什么”的核对。额外物证奖励深度结局和附加印章。

**结构**：旗舰章节使用 2–3 条可自由排序的调查线，每条由“问题 → 行动 → 发现 → 核对 → 后果”构成；完成两条基础线即可继续，第三条提供更完整的论证或彩蛋。

**辅助**：长时间无进展时才渐显方向；移动端提供“扫描当前区域”，键盘和文字列表拥有等价路径。

**错误兜底**：无结果搜索不改变状态并给出更具体的提问方向；错误证据组合保留选择，可直接修改。

**当前状态**：确定性搜索、热点、证据纸、查证和错误反馈已存在；仍需减少线性节点感，把多个现场动作组织为少量完整调查线。

### 6. 证据板：从收集转为形成主张

**玩家看到**：三类卡片分区：事实、证言、工作假设。系统不把假设自动升级成事实。

**玩家做**：把两到三张材料连成一条关系，选择“这组材料现在最多能支持什么”。

**完成条件**：形成一条有证据边界、玩家愿意负责的阶段主张，解锁公开论证。

**进度表达**：不显示“100% 修复度”逼玩家清空清单。只说明“当前主张还缺哪一类依据”或“已经足够公开，仍可继续调查”。

**当前状态**：线索簿与查证存在，尚无统一的事实/证言/假设分区和可视化关系板。

### 7. 公开论证：把证据用于回答，而不是猜系统白名单

**玩家看到**：知乎式回答编辑与评论对质。刘看山提醒玩家只发布自己愿意负责的说法。

**玩家做**：

1. 从“事实陈述 / 有边界的工作假设 / 越界断言”中选择或收窄主张；
2. 用证据回应 2–3 个不同质疑；
3. 必要时撤回、替换证据或改写主张。

**完成条件**：质疑被足够材料回应，或玩家主动决定暂停公开并保留记录。

**反馈**：可信度表示论证是否清楚；暴露度表示公开表达的风险。赞同数只负责演出，不代表真相。

**失败恢复**：无关证据不消耗；越界可以收窄后再试；只有真实违反平台语境的越界回答才演出“被折叠”，主动撤回不能写成平台处罚。

**内容边界**：《蓝血》开放内容只允许得出阶段主张，不能指认真正组织或解释世界为何变化。

**当前状态**：新的 claim/case Boss、可信度/暴露度、错误不消耗和存档恢复已有；`post` 社区场景已接入《蓝血》流程。事实、证言、工作假设仍未收束为同一张可视化关系板，这是当前论证链最明确的 UI 缺口。

### 8. 阶段结局：先讲因果，再讲评级

**玩家看到**：本章实际结果、仍未知的问题、两到三个造成结果的关键选择。

**玩家做**：查看“这次为什么停在这里”和“距离另一条路线差在哪一步”。

**完成条件**：玩家理解自己的选择改变了表达、关系或调查方式，而不是误以为猜出了原作未公开真相。

**当前状态**：阶段结局、抉择回放和原文入口已有；反事实复盘“另一条路线差在哪一步”尚未实现。

### 9. 调查人格：把这一局变成可认领的身份

**玩家看到**：刘看山揭晓八种调查人格之一，对应一张专属角色形象；程序在留白区写入固定名称、预写吐槽和三条本局真实选择依据。LLM 以后可以改写语气，但不参与判型，也不是完整体验的依赖。

**玩家做**：展开人格卡、查看附加印章、保存或分享。

**完成条件**：即使没有 LLM 和登录，也能稳定生成一张有固定文案的基础卡。

**判型**：只使用必经选择的“证物/人证、追击/克制、公开/隐蔽”三轴；可选操作只生成附加印章。详见 [INVESTIGATOR-PERSONAS.md](INVESTIGATOR-PERSONAS.md)。

**当前状态**：已实现。`Choice.personaSignals` 将《蓝血》三个自然必经二选一分别映射到三轴，稳定 `choiceId` 记录可在文案改动后回放；穷举测试证明正式《蓝血》八种组合全部可达，每条依据都能回指本局真实选择。8 张专属刘看山透明人格图已接入；无 LLM 时使用固定名称、吐槽和鼓励文案，仍能完整揭晓与分享。

### 10. 分享回流：图片能独立传播，链接能一步入局

**玩家看到**：保存高清 PNG、系统分享、复制链接三个能力，以及“阅读开放原文”“换一种查法”“看看其他故事”。

**分享图片**：内含人格名称、刘看山、无剧透行为依据和真实故事入口。当前卡片写入可复制链接；二维码/短链接属于后续增强，不阻塞回流。

**分享链接**：当前落地先由刘看山接站，并突出对应故事门，再由朋友自己决定是否进入；后续可增强为先展示朋友的人格卡。链接只携带 `story`、`from=persona-card` 与人格代码，不携带存档、用户资料或剧情答案。

**优先级**：

1. 保存 PNG + 真实可复制入口；
2. Web Share API / 复制链接；
3. OAuth 个性化和真实统计。

**当前状态**：已实现 Canvas `1080×1440` PNG 保存、Web Share（支持文件分享时连图片一起分享）和复制链接；系统分享不可用或失败时自动降级为复制入口。角色图加载失败时仍能导出文字版卡片。当前没有二维码和独立人格结果落地页，但匿名回流主路径已成立。

## 5. 全程不变的规则

1. **不设目标游玩时长，也不做选择倒计时。** 演示路线可以更短，但不能改变玩家版规则。
2. **关键通关零自由文本硬判定。** 自由输入增加代入和表达，结构化话题、选择与证据规则负责推进。
3. **错误产生信息，不产生死局。** 错问、错搜、错证都应帮助玩家缩小范围。
4. **每条硬证据有来源；每个主张有边界。** 原作事实、角色证言、玩家推断分开。
5. **刘看山引导行动，不替玩家推理。** 他可以说下一步做什么，不能说真相是什么。
6. **没有登录、LLM 或动态数据也能走完整流程。** 外部能力增强体验，不承担生死路径。
7. **视觉素材必须有玩法位置。** 场景图用于当前处境和调查；纸张用于可操作证据；刘看山素材对应明确引导状态；没有使用场景的素材不生成。

## 6. 当前是否可以定案

### 可以锁定，不再重开

- 网站先由刘看山接站，故事库随后出现；旗舰故事置顶，但不替玩家自动进入。
- 刘看山是有形象、有对白、会开门的引路狐，同时承担系统引导职能。
- 主循环为“处境 → 社区信息 → 私信 → 现场调查 → 证据板 → 公开论证 → 阶段结局 → 调查人格 → 分享回流”。
- 流程按状态推进，不按分钟、倒计时或强制全收集推进。
- 《蓝血》只得出阶段主张并引流原文，不补写全书真相。
- Boss 是公开论证，不是猜唯一嫌疑人；赞同数不是裁判。
- 八型人格只由必经选择决定，LLM 只写卡片留白文案。
- OAuth、真实热榜与关注关系均为可选增强，不能阻塞首局。

### 已从方案进入实现

- 《蓝血》三处必经选择已经写入三轴信号，八型穷举可达；旧存档保留兼容回放。
- `post` 社区场景、关键虚构账号、错误账号回退与离开条件已经写入《蓝血》。
- 8 张刘看山透明人格图、固定文案、真实选择依据和分享卡已经接入结局。

### 仍需完成的体验闭环

- 把事实、证言、工作假设统一到可视化关系板，不让玩家在多个抽屉里自行拼接论证链。
- 为阶段结局补上反事实复盘，明确“另一条路线差在哪一个真实选择”。
- OAuth 与真实热榜仍是可选增强，当前没有接入；首局不得依赖它们。
- 完成 5–8 名未读文档玩家盲测，并据卡住位置、误解和分享意愿调整流程。
- 完成最终新存档 Ego 全流程、375px/1440px 关键路径与公网当前版本验收。上述验收完成前，不宣称全链路已发布。

## 7. 开发 Go / No-Go

只有以下全部成立，才可以称为“整体流程已落地”。截至 `main@dc8bed6`，自动化测试 76/76、TypeScript 检查和生产构建通过；下面仍有人工与公网验收项未完成：

- 新玩家从公网根路径先看到刘看山角色化接站，再亲手选择一扇故事门；页面不能自动进入《蓝血》或其他故事。
- 从第一幕到人格卡全程不使用 `?scene=` 跳转，也不会出现无回应、无出口或必须刷新才能继续。
- 不做可选探索也能到达一个合理阶段结局并获得八型之一。

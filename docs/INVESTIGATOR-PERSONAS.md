# 看山调查人格：八型分享卡设计

> 状态：八型判定、章末揭晓、8 张刘看山角色图、Canvas 分享卡、PNG 保存、Web Share 与匿名回流链接已实现；独立人格落地页与可选 LLM 文案改写尚未接入。
>
> 定位：借鉴趣味人格卡“容易认领、方便玩梗、适合比较”的传播方式，但角色、名称、判词、视觉和判型规则均为《看山任意门》原创。八张角色图统一使用已授权的刘看山形象。

## 一、判断原则

它判断的不是“你现实中是什么人”，而是“你这一局习惯怎样查案”。

- **只用游戏内可确认行为**。不能判断用户有没有截图、转发、在别处搜索或与别人讨论。
- **主类型只依赖必经选择**。即使玩家不点任何可选彩蛋，也一定能得到合理结果。
- **可选探索只生成附加印章**，不改变主类型，例如“折叠区潜水艇”“暗号捕手”“重开战神”。
- **规则引擎判型**，同一行动记录永远得到同一结果；LLM 不决定人格。
- **当前固定文案直接可用**。未来如让 LLM 填文案空位，也只能引用程序提供的结构化行为事实，不能编造玩家做过的事。
- 每张卡至少展示 2–3 条真实选择依据，对外称“本局调查人格”，并标注“娱乐性结果，不是心理测量”。

## 二、三个必经选择轴

每个旗舰故事必须把三条轴写进必经选择：每条轴至少取得一次明确信号，完整章节最好由两个不同节点共同确认；章末立场选择负责裁决仍然打平的轴。

| 轴 | 一端 | 另一端 | 游戏中怎样体现 |
|---|---|---|---|
| 判断入口 | **证物** | **人证** | 先查记录/现场，还是先问当事人；最终更愿意用哪类材料支持判断 |
| 推进姿态 | **追击** | **克制** | 继续追问/追踪/对质，还是先收窄结论、观察并保留余地 |
| 发声方式 | **公开** | **隐蔽** | 实名公开、邀请共同核验，还是匿名求助、保护身份、先留草稿 |

三条轴各有两端，组合成 `2 × 2 × 2 = 8` 种主类型。作者只为关键选择标注 `personaSignals`；普通翻页、停留时长和界面点击不参与人格判断。

如果某条轴打平，由章末必经立场选择裁决。任何结果都不依赖用户完成某个隐藏操作。

## 三、八种主调查人格

### 01 FIRE · 热榜点火器

**证物 × 追击 × 公开**

- **玩家确实做过**：优先拿硬证据、主动推进对质，并愿意把可验证的主张公开。
- **固定吐槽**：你不是来围观热榜的，你是来给热榜安排加班的。
- **正向解释**：你敢发声，但不是空手冲锋；你希望问题进入公共核验。
- **刘看山形象**：一脚踩住“发布回答”按钮，一手举证物袋，背后窜起蓝色热榜火焰。

### 02 ANON · 匿名拆弹员

**证物 × 追击 × 隐蔽**

- **玩家确实做过**：持续追查硬证据，同时隐藏身份或控制公开范围。
- **固定吐槽**：线索可以实名，调查员暂时不必。
- **正向解释**：你推进得很快，却知道活着把证据带回来比抢镜重要。
- **刘看山形象**：戴兜帽和护目镜剪断“谣言/事实”两根线，尾巴卷着匿名面具。

### 03 CLEAN · 证据洁癖

**证物 × 克制 × 公开**

- **玩家确实做过**：更依赖材料，愿意公开，但会主动收窄说法、区分事实和假设。
- **固定吐槽**：没有来源的消息，到你这里连八卦都算不上。
- **正向解释**：你不是胆小，你只是拒绝替证据说它没说过的话。
- **刘看山形象**：戴白手套，用放大镜逐字检查纸张，旁边摆好编号证物袋。

### 04 CTRL · 草稿保险柜

**证物 × 克制 × 隐蔽**

- **玩家确实做过**：保存材料、暂缓定论、控制身份暴露，把尚未证实的内容留在草稿里。
- **固定吐槽**：能说的写结论，不能说的连冲动一起存草稿。
- **正向解释**：你不急着成为第一个喊出答案的人，但不会让证据消失。
- **刘看山形象**：坐在小保险柜上，把证物纸塞进“草稿”抽屉，另一只手调节公开范围旋钮。

### 05 ECHO · 证词扩音器

**人证 × 追击 × 公开**

- **玩家确实做过**：主动追问人物、重视证词，并愿意把当事人的问题带到公开讨论中。
- **固定吐槽**：别人刚说完悄悄话，你已经替它配好了热榜标题。
- **正向解释**：你擅长让被忽略的声音进入讨论，但仍需保留证词边界。
- **刘看山形象**：举着扩音喇叭，喇叭里飞出对话气泡而不是文字，身后是匿名人群剪影。

### 06 ASKR · 私信永动机

**人证 × 追击 × 隐蔽**

- **玩家确实做过**：持续私下追问、从人物关系推进调查，并倾向保护谈话对象和自己的身份。
- **固定吐槽**：别人说“没事”，你已经在私信里问到了第三幕。
- **正向解释**：你知道第一句话很少是完整答案，也知道有些答案不能在广场上逼出来。
- **刘看山形象**：左右手各拿一台冒出气泡的手机，背后拖着长长的问号清单。

### 07 FAIR · 人话公证员

**人证 × 克制 × 公开**

- **玩家确实做过**：重视人物说法，愿意公开整理，但不会把态度、猜测和证言混成事实。
- **固定吐槽**：负责把评论区的人话翻译成人话，并附上出处。
- **正向解释**：你让不同立场被听见，也替每句话保留了它原本的边界。
- **刘看山形象**：站在两组争论气泡中间，拿印章给“亲眼所见/个人猜测”分别盖章。

### 08 FEEL · 人情线雷达

**人证 × 克制 × 隐蔽**

- **玩家确实做过**：优先保护关系和身份，认真听取证言，在真相未明时给当事人保留空间。
- **固定吐槽**：案子还没破，证人已经愿意把真话留给你了。
- **正向解释**：你查的不是冷冰冰的谜题，你记得每条证词后面站着一个人。
- **刘看山形象**：拿着两杯热饮坐在证人旁边，柔和雷达波纹连接心形和对话框。

## 四、可选行为只做附加印章

这些内容只有玩家真的做过才显示，不参与八型主判定：

| 印章 | 触发依据 |
|---|---|
| 折叠区潜水艇 | 实际打开足够多的折叠回复、编辑记录或引用 |
| 暗号捕手 | 实际发现并使用了可选暗号 |
| 地毯式搜证 | 找到本章绝大多数可选物证 |
| 假设守门员 | 多次主动把越界结论退回假设区 |
| 折叠重开战神 | 经历失败后重开，并确实改善论证或结局 |
| 关系维护员 | 在可选节点保护了证人身份或维持联系 |

“截图囤积者”不作为判型或印章。网页无法可靠知道用户是否真的截图；除非以后游戏内增加明确的“存入调查簿”按钮，才可以根据那个按钮产生“记录囤积者”印章。

## 五、固定文案优先；未来 LLM 只可填空

八张刘看山角色图是预生成的透明 PNG/WebP，只包含人物、动作和少量无文字道具。卡片背景、标题、数字、真实入口和个性化判词均由前端排版，因此文字不会乱码，也能随玩家改变；二维码如后续加入也应由前端生成。

当前生产版直接使用每种人格的人工固定吐槽、鼓励和真实选择依据，不调用 LLM。以下结构保留为未来可选语气改写契约，不是现有主路径依赖。

程序向 LLM 提供：

```json
{
  "persona": "CLEAN",
  "axis": { "source": "evidence", "pace": "restrained", "voice": "public" },
  "endingTitle": "阶段性真相",
  "observedFacts": [
    "核对了两张题型不同的试卷",
    "把世界被替换保留为假设",
    "公开发布了可复核的记录"
  ],
  "optionalBadges": ["假设守门员"]
}
```

LLM 只能返回四个受长度限制的槽位：

```json
{
  "roast": "不带出处的消息，在你这里甚至不能参加八卦。",
  "praise": "你愿意公开问题，也愿意为每句话负责。",
  "proofLines": ["…", "…", "…"],
  "shareCaption": "我的调查人格是 CLEAN，你会怎么查？"
}
```

- `roast` 18–32 字；`praise` 20–44 字；每条依据不超过 26 字。
- 只能改写 `observedFacts`，不能新增行为、心理诊断、玩家群体比例或故事真相。
- 上游失败、超时或输出不合规时，立即使用每种人格的人工固定文案，卡片照常生成。
- 自由聊天原文、搜索原句和真实知乎身份不发送给人格文案模型。

## 六、卡片如何保存、转发并引流

### 卡片合成

- 主版式使用 `1080 × 1440`，适合手机保存和社交平台图片分享。
- 上半部是对应人格的刘看山透明角色图；下半部是固定留白信息区。
- 前端直接在 Canvas 中排版动态文字和透明刘看山角色图，再导出高清 PNG；不让图像模型烘焙中文。
- 卡面包含：人格代码、搞笑名称、吐槽、正向解释、2–3 条选择依据、附加印章和无剧透路线指纹。

### 两种分享路径

1. **保存图片**：一键生成 PNG。当前图片写入真实故事网址与匿名人格参数；二维码和短链接是后续增强。
2. **分享链接**：优先调用移动端系统分享；不支持时复制链接。朋友打开后先进入刘看山接站页，并看到被突出显示的故事门；独立人格结果落地页是后续增强。

分享链接携带匿名活动参数和故事 ID，例如 `from=persona-card&persona=CLEAN`，只用于统计引流，不恢复或泄露分享者的剧情存档。

### “3%”的正确用法

在没有真实玩家统计前，低百分比只表示**本局行为值**，例如：

> 轻信值 3% · 本局行为值
> 你把两个诱人的结论留在了假设区。

它由本局选择计算，不写成“只有 3% 玩家获得”。拥有足够真实样本后，玩家占比作为另一项独立数据展示，并写明时间范围和样本口径。

## 七、实现所需的数据

主类型最小实现只需：

- 给必经选择增加 `personaSignals: { evidence, testimony, push, restrain, public, private }` 权重。
- `memo` 保存 `choiceId` 和这组权重，不再只保存显示文本。
- 章末累计三条轴并映射到八型。
- 将最终类型、2–3 个代表选择和已触发印章传给文案生成器。

可选印章再按功能逐步增加事件：`comment_expanded`、`edit_history_opened`、`dialogue_topic_completed`、`clue_found`、`verification_attempted`、`loop_improved`。这些事件只记录 ID 和结果，不保存玩家输入原文。

## 八、验收条件

- 不进行任何可选探索，也能仅凭必经选择得到八型之一。
- 为 8 种人格各写一条固定选择序列测试，并稳定命中预期类型。
- 同一存档重复计算结果完全一致，LLM 不可改变人格类型。
- 卡上每条个性化描述都能回指真实选择；没有“你截图了”“你看了某楼”等未发生行为。
- 没有登录、没有 LLM、上游接口失败时，仍能用固定文案生成和保存人格卡。
- 八张刘看山角色素材不包含生成文字，透明背景、轮廓完整，在卡面浅色和深色区域都清晰。
- 分享图片带可读真实入口；分享链接落地后先进入刘看山开场引导，并突出对应故事门。

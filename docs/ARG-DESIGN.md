# 知乎原生伪界面悬疑设计（2026-09-14）

> 综合两路并行研究（[ARG 经典与原则](research/arg-classics-20260914.md) / [伪界面悬疑机制](research/interface-mystery-20260914.md)）+ 知乎开放平台能力盘点。
> 本文是「评论区玩法 → ARG 质感」升级的设计依据，GDD v1.1 的配套文档。

## 一、形态定义

本项目吸收 ARG 把叙事藏进熟悉媒介、让玩家主动考据的质感，但**不执行严格 TINAG**：入口有刘看山、任意门和明确的互动首章身份，不欺骗玩家这是现实事件。

准确形态是**「知乎原生伪界面悬疑」**：帖子、评论、私信和公开论证构成社区信息层，任意门后的现场还原承担亲历与搜证。差异点不是“所有页面都长得像知乎”，而是**知乎的内容关系与社区行为本身成为玩法**。

## 二、三层配方

### ARG 原则层（单页版）
媒介细节（时间戳/作者赞过/已编辑/折叠）→ 碎片叙事（正文、评论、私信各有知情边界）→ 可选暗号（奖励细看但不阻塞）→ 模拟集体智能（脚本账号持续争论与考据）→ 状态驱动的新回复 → Curtain Call（游戏复盘、原作与改编致谢）。

### 可抄机制层
点选关键词进线索笔记（Orwell）；搜索框单次限 5 条防暴力破解（Her Story）；关键 ID 档案卡随发现解锁（Profiler）；点赞数叙事化（异常高赞=路标）；「正在输入…」「x 分钟前在线」（Emily is Away）；噪声评论池每条独立人设（Hypnospace）；私信分支；章末 3 题批量验证（Obra Dinn）；评论蓝字外链伪页面。

### 知乎原生层（别人抄不走）
真实知乎搜索结果可在编译期形成带来源的资料卡；真实热榜提供 Boss 的当日语境对照；OAuth 可展示玩家自己的昵称头像和其关注的相关公开内容入口。**不得替真实关注答主编造剧情评论、证词或立场。**

## 三、真实感配方与体量

时间戳符合作息，点赞呈长尾，允许少量错别字与跑题楼；每个虚构 ID 有稳定口癖，楼主语气跨楼层一致。噪声只服务真实感，不能把有效玩法埋进机械滚动。
体量：首个旗舰场景 18–30 条可读评论、关键账号 3–5 个；其余数量以折叠楼和计数营造。每一屏至少提供一个可理解的信息变化或行动入口。

## 四、知乎能力地图（盘点结论）

| 能力 | 额度/天 | 玩法化 | 档位 |
|---|---|---|---|
| 知乎搜索 | 5000 | 关键词真实检索 → 物证打印件（编译期预缓存，运行时零调用） | P0 |
| 全网搜索 | 5000 | 跨平台证据对照（蓝血地标线天然需要） | P0 |
| 热榜 | 100 | 门厅氛围 + Boss 真结局「如果今天发能进前 X」对照 | P0 |
| 直答 | 100 | 不扮演 NPC（实测拒绝），做刘看山系统分析音/人格侧写 | P1 |
| 问题发现+回答摘要 | 100 | 噪声评论真实感素材 | P2 |
| OAuth 基础信息 | — | 玩家真昵称头像进评论 + 人气奖登录数 | P1 |
| OAuth followees | — | 相关公开内容/创作者入口；不替真人编写剧情发言 | P2 |
| OAuth contents/收藏 | — | 楼主历史发言/收藏彩蛋 | P2 |

工程红线：①额度全账号共享——搜索类必须编译期预缓存，热榜每天缓存 2-3 次；②OAuth 凭证需创建项目后领取（开发期先 Mock）；③玩家数据只进不出、最小化使用。

## 五、故事池包装模板（三类角度全覆盖）

| 角度 | 适用 | 例 |
|---|---|---|
| 当事人求助/吐槽 | 现代悬疑、甜宠秘密 | 蓝血《现在怎么还有这么没常识的人》；史密斯夫妇《怀疑男朋友在装穷》 |
| 旁观者考据/扒皮 | 修仙/西游/权谋 | 西游《如果西天取经是个阴谋》 |
| 游戏内社区 | 无限流/末世游戏文 | 末世钞能力《这游戏是不是不对劲》 |

关键洞察：盐选故事天然是「有钩子的事件」，ARG 吐槽帖就是「把钩子事件用第一人称讲出来」。A 类 8 篇全适配（蓝血/追杀为 ★★★★★，原文自带社区情节）。

## 六、落地改造清单（接现有架构）

| 改造 | 接在 | 优先级 |
|---|---|---|
| post 场景：剧情时序内的帖子+评论流+回复判定（相关人物→私信/无关人物→缩小范围） | 新场景类型，视觉复用 Boss 楼层 | P0 |

| 人物档案卡（关键 ID 解锁） | 复用 NPC 卡 | P1 |
| 章末批量验证 3 题锁进度 | 现成 InvestigationCheck | P1 |

| Curtain Call 复盘揭示页 | 结局页扩展 | P2 |

## 七、看山的角色（定案）

刘看山 = 玩家可见的引路狐，同时承担系统引导职能。他在故事门完成角色化开场，在帖子里跟评吐槽，在转场时开门，在卡关时递台阶，在通关时主持复盘与调查人格揭晓。他只知道当前玩法状态，不知道原作未公开的真相。官方 GIF/立绘素材已入库可直接用。

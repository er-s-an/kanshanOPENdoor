# 看山任意门：玩家体验验收单（2026-09-14）

> 目标不是证明页面能打开，而是证明一个第一次来的玩家无需开发者解释，也能从网站入口走到可保存、可分享的章末结果。

## 必测环境

- 桌面端 1440px：正常网络、新存档。
- 移动端 375px：正常网络、新存档。
- 返回玩家：已有一篇故事的中途存档。
- 降级模式：关闭 LLM；OAuth、热榜均不可用。
- 深链：普通 `?story=` 与仅供评审使用的 `?scene=` 分开测试。

## 必经路线

| 阶段 | 玩家必须能理解并完成 | 失败条件 |
|---|---|---|
| 网站接站 | 看见刘看山，知道这里有多扇故事门；点击唯一主按钮 | 加载后自动进入故事；必须先读故事目录才能理解产品 |
| 选择故事 | 比较故事钩子，亲手选择或继续存档 | 整张背景假装可点；链接替玩家自动进入；返回后丢失进度 |
| 开门 | 选择后获得即时反馈，动画结束进入所选故事 | 动画反复用于故事内部；图片失败导致永久卡住 |
| 故事简报 | 三句话内知道身份、异常和第一步 | 长教程弹窗；刘看山直接说答案；跳过后没有可做动作 |
| 社区信息 | 浏览帖子/评论，选一位相关人物继续追问 | 评论只是装饰；回复错误账号扣资源或形成死路 |
| 对话 | 推荐话题和自由输入都能获得回应，关键证言由规则授予 | 发出后无反馈；LLM 决定线索或胜负；失败后没有主线出口 |
| 搜证 | 可点现场或输入词搜索；错搜、歧义搜索都可恢复 | 未发现信息提前泄露；满屏同质光点；错一次永久消耗机会 |
| 核对 | 把记录组合成明确、有限的判断 | 纸张只是装饰；反馈只写对错，不说能证明和不能证明什么 |
| 公开论证 | 先选择愿意负责的主张，再逐项回应质疑 | 猜唯一幕后；点赞数充当真相值；无关证据造成软锁 |
| 阶段结局 | 看到本局造成的结果、仍未知的问题和下一步 | 把开放片段写成完整真相；玩家不知道自己的选择改变了什么 |
| 调查人格 | 八型之一稳定命中，并列出 2–3 条真实行为依据 | 根据截图/停留时长猜测；LLM 改变人格；伪造玩家比例 |
| 保存分享 | 生成 1080×1440 PNG；能系统分享或复制匿名链接 | 卡片中文烘焙乱码；没有回流入口；分享泄露存档或自由输入 |

## 恢复性动作

以下动作都必须在 ego-browser 中实际做一次，而不是只看单元测试：

1. 搜索一个完全无关的词，然后继续找到真实线索。
2. 对话上游无回应时，从刘看山兜底回到结构化话题或跳过。
3. 在公开论证中呈上一张无关或越界证据，再改用有效证据。
4. 中途刷新页面并继续当前故事；返回门厅后再次进入。
5. 在 375px 下打开输入法区域、线索簿、证据选择抽屉和人格卡。
6. 开启 `prefers-reduced-motion`，确认没有不可跳过的长动画。

## Go / No-Go

只有以下结果全部成立才发布：

- `npm run typecheck`、`npm test`、`npm run build` 全绿。
- ego-browser 从干净入口完整到达人格卡；没有使用 `?scene=` 跳关。
- 375px 与 1440px 均无横向溢出、遮挡主按钮或双层滚动死区。
- LLM、OAuth、热榜全部关闭时，仍能完成主线、得到人格并保存卡片。
- 浏览器控制台没有未处理异常；失败提示包含恢复动作。
- 公网重启后再重复关键路径，确认不是只改了本地未运行版本。

## 本轮发现并修复

1. 桌面场景行占满高度，实际对话与分支选项被挤到不可见区域：改为给舞台和对话分别保留有界网格行，并在展开分支后滚到底部、聚焦第一个可用选项。
2. Boss 证据没有按当前质疑的适用性排序，玩家只能靠猜：增加直接支持、部分支持、越界、无关、已使用五级排序与可见标签。
3. 证据纸底图处于负层级，在深色按钮中被遮住，形成黑字压黑底：修正隔离堆叠顺序并增加 CSS 回归测试。
4. 旧故事没有新版人格标注时缺少反事实：复用人格兼容判型，从真实已写选择中找到对照分支。
5. 结局曾优先复盘较早的一般选择，忽略更晚的 Boss 主张：当最终公开主张构成有效分歧时，优先复盘它的证据边界。

当前判定：**工程发布候选与公网完整体验为 Go；“目标玩家已经证明它有趣、愿意停留或分享”为 No-Go。** 原生系统分享选择器未在无人值守时打开，PNG 下载和复制回流已验证。

# 看山任意门 · 玩家体验与信息层级打磨

日期：2026-09-13。承接 PRD v2.2，本轮修改前端体验；三篇故事、剧情分支、角色、线索授予规则与正文版本保持不变。

## 设计决定

主界面依次回答三个问题：我在哪里、眼下能做什么、我掌握了什么。故事和人物的表达是主体；操作就近出现；规则解释、全部记录、连接状态与纪念卡按需展开。

采用深墨绿、暖灰正文与少量金色行动提示；中文正文18–19px，限制阅读行宽。手机按单列组织，桌面对话才将指引放入右栏。取消每幕全屏闪光、强制等逐字和逐个显现选项；逐字阅读成为可选设置。

## 具体变更

| 原来的摩擦 | 已落地的处理 |
|---|---|
| 大封面横向滑动，其他故事不容易发现 | 改成纵向故事索引：题材、名称、原作者、处境、进入按钮与原文入口；继续上次单独呈现 |
| 故事阅读与设置抽屉共用 `.sheet`，样式互相覆盖 | 阅读页与工具抽屉分离，正文有独立行宽、滚动区和段间距 |
| 章节名很小，长标题在手机挤出孤行 | 故事与章节序号为辅助信息，当前场景标题为主；记录和设置固定在顶栏 |
| 每幕都要点加速、等待动作逐个出现 | 默认全文阅读，选项同时出现；设置中可选择逐字呈现与速度，取消强闪光过渡 |
| NPC气泡嵌套两次76%宽度，形成窄长文字柱 | 只限制外层宽度；NPC正文18px，手机和桌面分别排版 |
| 目标、全部话题、重试、输入与继续竞争 | 桌面指引分栏；手机话题按需展开，已问内容折叠；输入与当前有效出口就近呈现 |
| 未问话就高亮“继续”，点进去才发现全锁 | 根据实际可用出口显示推进；单出口直达，允许返回现场的场景仍可返回 |
| 回复和证言全文重复，未知记录名又提前泄底 | 默认为“已记下”摘要，规范证言可展开；待办提示指向可问的话题，不展示未知证言名称 |
| 搜索、空记录框、问题卡、证据全文一次铺满 | 调查拆成观察/查证两个工作区；无查证题时只显示观察；搜索作为辅助展开 |
| 查看物件后要拖回顶部找下一处 | 记录内提供返回列表和下一处；看完后用就近行动继续，已知记录可重读 |
| 查证失败/成功后下一步不清楚 | 保留所选证据，错误可直接改；成功先显示结论与继续入口，依据折叠 |
| 线索簿24–28条全文太长 | 默认本幕相关，支持全部记录和搜索；条目展开阅读，不展示未知线索待收集总数 |
| 设置缺少明确关闭和键盘焦点恢复 | 对话框语义、Escape关闭、Tab循环、关闭后恢复触发按钮；重开明确提示进度替换 |
| 结尾延时揭示、巨大海报挡在下一步之前 | 尾声→阶段结果→本次真实选择→回门厅；完整记录和纪念卡可选展开，生成卡片时才挂载 |

## 后续体验维护原则

新玩法接入仍使用“当前处境→可执行动作→反馈→下一步”的页面结构。新增信息先判断是否影响当前决定；不影响的资料进入展开区。不得以玩法扩展替换原有聊天、完整叙事或搜证链路。

## 2. 最低测试组合

静态 fixtures 必含：可通关线性样例、有意义分支与汇合、物品消耗、循环、同名局部锚点、错误跨场景引用、隐藏目标、相互矛盾 guard、假 next、未知模板、来源 span 跨 Unicode 代理对、旧存档／损坏存档。

Browser 必含：桌面 Chromium 与 WebKit 的核心路径，键盘／鼠标与触控模拟，焦点丢失、暂停、双击、热重载／重复加载、长字幕、中文换行、Reduced Motion、音频未获手势许可时仍能推进。触控模拟不是手机真机证明；未跑真机明确记 NOT_RUN，不称移动端完整支持。

性能目标：在记录的参考桌面设备／浏览器／视口上，10 分钟游玩 p95 frame time ≤ 33.3 ms，无持续输入失灵；记录冷启动、JS／资产体积和峰值 WebGL 资源。此门槛是拟定目标，不是当前跑分；S02 首测后若需改门槛，写原因和前后值，不能默默降标。

## 3. 自然通关证明

录像／事件轨迹包含从标题到边界页的完整路径、用时、revision/digest、模板版本。可以用测试 hooks 读状态定位问题；跳章、瞬移、直接设 flag 只能算调试，不计 T15。

至少一次刷新恢复发生在真实操作后的 beat 边界。选项可达、世界变化、任务提示和最终来源说明都有证据。每个自动测试写出当前版本、步骤和失败位置；历史截图不自动继承到新包。

## 4. 内容与玩法审阅量表

每项 0–2 分：0 未达标；1 可用但需修正；2 满足目标。两名评阅者独立记录，不知道实验分组，分歧附说明。

1. 来源支持：关键事件可追溯，角色判断未升格为事实。
2. 信息顺序：玩家和角色的知情范围合理，没有名称／HUD／日志剧透。
3. 片段边界：未冒充完整作品、未捏造答案／后续结局。
4. 行为贴合：行动来自故事事件，而非所有故事换皮收钥匙。
5. 空间与反馈：能理解去哪、做什么、结果是什么。

公开样本前三项每位评阅者均须 2 分，后两项均不为 0；另满足至少两项空间行动与一次状态变化。分数不是授权认定，也不能用总分掩盖来源问题。

## 5. AI 价值报告模板

记录 `storyId / sourceDigest / runId / group / host-or-provider / model / prompt&skill version / engine&template digest / cache policy / budget / modelCalls / repairRounds / wallTime / tokens&cost-or-unknown / manualEdits / playtest / editorialReview`。

手工编辑区分：改文字、改结构、改布局、改引擎。只要留出阶段修改引擎／模板，当前复用性尝试记失败，升级版本后重新冻结，用另一篇未见片段重测；修好后不能继续把原故事称严格留出。

先报告样本数和完整失败分布，再讨论效率；没有显著或一致改善也要呈现。可展示价值是可追溯的自动化工作与真实游戏结果，不是 Skill 文件长度、模型调用次数越多或宣传中的评分百分比。

## 浏览器实际操作

使用隔离的本地18792预览、明确的预写对白模式，从蓝血开场走到e_web收束，无场景跳转，无手工灌入线索。已操作并观察：

1. 三篇完整故事出现在门厅，短样例不再占主入口。
2. 张薇自由输入问题 → 证言1/1 → 线索簿2/24 → 选择解锁。
3. 未取得证言先开选择页，按钮灰显；仍能返回继续交谈，避免软锁。
4. 刷新后继续上次，聊天记录、证言与场景一致恢复。
5. 搜不存在关键词得到空结果，可显示全部并继续查看物件。
6. 错误证据组合有具体反馈；改用正确组合后新增推断并解锁出口。
7. 查两张试卷 → 普通询问没有新关键证据 → 出示差别追问 → 记录培训师回避 → 推进答卷选择。
8. 后续餐厅／便利店／死胡同／纸上问题连续推进，最终24/24记录与开放原文入口出现。
9. 展开全文的按钮一次显示所有段落；结算页在默认窄屏下可阅读。

浏览器试玩发现并修复：

- 全文按钮的 pointerdown 冒泡触发段落跳过，干扰一次展示全文。
- 线索 toast 的清理逻辑会让提示滞留并挡住聊天按钮；现在独立计时且不拦截点击。
- 场景切换期间推进按钮没有对应禁用态；现在与引擎导航状态一致。
- 对话组件随 saveChat 身份变化触发卸载逻辑、打断请求；改成稳定引用与明确存档时机。

## 不应误报的边界

- 完整首章不等于取得全书正文。现有两篇源正文各3000字、都截断；原文未知继续保留。
- 蓝血做过上述完整浏览器路线；近视的全路径以规则级集成测试为证据，尚不能代替真人从头到尾试玩。
- 多幕打包器做契约／图／线索固定点校验，明确标记动态资源状态未穷尽；游戏流程测试另外使用真实规则验证实际包。
- 关键话题由配置关键词匹配，不宣称任意自由表达都能语义授证。AI自由交谈与固定证言明确分工。
- 本机存档可被玩家自己修改。没有跨用户权威进度、真实帮助池、知乎好友匹配或帮助回执，不发放虚构社交奖励。
- 15–20分钟仅是设计目标，未经真人样本测量。是否好玩、是否愿意重玩，需要观察真实玩家。

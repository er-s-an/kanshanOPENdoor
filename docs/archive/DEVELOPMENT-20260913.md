## 下一步最小开发单

**只做一个互助端口：整理方法使一次清理少消耗 1 体力。**

1. 建 run/session 与持久化事件表，服务器复用 `rules.mjs` 回放；提交 actionId + 序号，拒绝伪造结果和重放。
2. `clean_surface` 真实完成后产出候选帮助，玩家确认发布；记录版本、节点、模板端口与匿名贡献者。
3. B 在兼容节点采用，服务器事务性记录已用并应用折扣；仍需 B 自己执行清理与照料。
4. 两个独立浏览器会话 A→B→A 使用回执验收；断网/重复领取/自领/旧版本/错误进度全有确定结果。
5. 再处理 OAuth 和关注排序。没有 app_id/app_key 或可验证标识映射时，保留真实陌生人互助，不造好友数据。

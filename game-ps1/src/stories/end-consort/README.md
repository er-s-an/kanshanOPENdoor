# 端妃黑又壮 · 景华宫的日子

独立网页入口为 `end-consort.html`。使用现有 `PS1Pipeline` 和 Three.js；院落、人物、纹理、手部、道具均程序生成，音效由 Web Audio 合成，无外部资产请求。

## 运行

在 `game-ps1` 目录：

```sh
npm run dev -- --host 127.0.0.1 --port 5188
```

打开 `http://127.0.0.1:5188/end-consort.html`。构建使用根目录已有的 `npm run build`；多页入口由项目整合方管理。

- 点击「推门，过我的日子」开始。
- WASD／上、下方向键移动；拖动画面转身，左右方向键也可转身。
- 靠近金色标记后按 E 或点底部操作按钮。E 在剧情段中只继续当前对白。
- 左侧「朝向下一件事」只转向，不传送角色。
- 触控环境提供方向按钮、拖动视角和点按交互。
- 右上角或末尾卡可从头重开；本切片不提供跨刷新进度存档。
- 右上角与末尾的「返回任意门」会回到门户深链 `?story=consort-3d`。部署在 `/myopia-3d/end-consort.html` 时会保留站点的子目录；独立打开时回退到正式门户入口。
- 末尾可保存景华宫记录卡；支持 Web Share 的浏览器会调用系统分享，不支持时会保存图片供手动分享。分享链接与二维码只包含故事深链，不带进度或选择数据。

## 真实玩法链

书箱与入宫回忆 → 看景华宫 → 福顺管账库 → 等青杏说完 → 三块地清草 → 松土 → 不到半个月的时间过渡 → 播种 → 德妃来访、讥讽并离开 → 实际低头拔草 → 听青杏安慰、安排红烧肉 → 拿镰刀、背门误认 → 原地回头才显露皇帝 → 原地放下镰刀并行礼 → 石桌谈话 → 洗手 → 三步棋势图 → 她本已胜、先认输、被点破、再承认赢 → 皇帝笑后重新露出倦意 → 原文 L177 半句停止。

剧情依据为本地现有缓存 `端妃黑又壮-1985108790006277782.txt`，作者重十八。开场 L10–76 为明确标注的回忆；庭院当前剧情 L78–177。正文对白、叙述转述、内心解释和原文截断均分标签显示。没有将「辟邪」的内心理解配给皇帝发声。

游戏新增仅包括任务牌、地块压缩操作、短暂等待动作和 7×7 棋势示意；棋势图不是原作棋谱或完整围棋规则。不设置外貌、宠幸、忠诚、饥饿或宫斗胜负数值。播种只显示种子，不立即长成萝卜；洗手只去掉土污，保留主角的肤色。

## 文件

- `main.ts`：剧情、状态门控、键鼠／触控操作、移动碰撞、手部、棋势图、合成音与结尾。
- `world.ts`：庭院、人物、程序纹理、三块地状态、锚点与碰撞盒。
- `style.css`：高清中文 HUD、对白、棋势图及响应式操作区。
- `verify.cjs`：真实浏览器行走和全链验收。它只读取开发环境快照，用键鼠移动和操作；没有传送、写入剧情状态或自动通关接口。
- `evidence/`：浏览器验收截图和运行记录。

验证脚本需要本机已安装的 Playwright，以及可用的 Chrome。可用 `PLAYWRIGHT_MODULE` 指定模块位置；默认尝试当前环境的已有依赖。Node 25 直接读取本故事的 TypeScript 世界模块用于计算避障路径，浏览器中仍用实际键鼠行走。

```sh
node src/stories/end-consort/verify.cjs
```

开发环境暴露只读 `window.__consortSnapshot()`，包含当前阶段、可见角色、手部土污、地块和事件记录。生产构建不保留该快照入口。

## 验收范围

结构与保真检查覆盖：全部锚点可到达；两本兵法和种子包；三喷嚏；不到半个月；德妃先离开再拔草；误认时背门且皇帝隐藏，原地回头才显示；洗手不改变肤色；棋局固定顺序；L177 截断。

具体浏览器检查结果见 `evidence/browser-run.json`。浏览器模拟的触屏检查不等于实体手机测试；无真人音频聆听、弱网耐久或真实性能基准。本目录没有部署行为。

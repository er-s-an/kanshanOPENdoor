## 运行

在 `game-ps1` 目录执行：

```sh
npm run dev -- --host 127.0.0.1 --port 5186
```

打开 `http://127.0.0.1:5186/blue-blood.html`，点击“开始篇章”。WASD 移动，拖动场景转头，方向键也可转头；靠近提示后按 E 或点击互动按钮。手机反射阶段使用角度滑块；Esc 暂停。触屏提供方向按钮与拖动视角。

章节自动保存在当前浏览器 localStorage，封面支持继续。保存粒度是章节开头，不是任意帧。一般探索状态可重试本章；剧情对话或固定观察进行时先完成这一段，或暂停。菜单和章末可从头重开。

## 当前覆盖

1. 急救培训：主角异议、教材、手机搜索、张薇关心。
2. 洗手间：一次性的本人红血确认，隔间门缝看到外面镜旁同事蓝血转红，纸巾与牙齿可见。
3. 王经理询问：方诺说玩笑，经理不追问。
4. 夜间：关窗、失眠、三个固定地标查询、帖子回复和删帖伪装。
5. 三天后考试：先看同事的急救试卷，自己的草稿必须填写蓝色和白色后才可提交；不判断是否真的过关。
6. 餐厅：调节手机反光角度看同一场景中的灰夹克三次抬头，随后正常吃饭；下午多次便利店偶遇用压缩过场呈现。
7. 旧街：实际穿行三个路口，购买关东煮、坐在玻璃前等待、天色变暗、查看空巷。人物先走到店侧墙的自然遮挡后，画面不展示隐身或传送。
8. 家中：反锁、喝冰水、逐条写“我的判断”、未写下的内心答案、问答残句与明确正文停止页。

## 实现边界

- 全部模型、标牌、材质、声音均本地程序生成；不请求故事 API、不下载素材、不实际发帖或注册外部账号。
- 使用已有 `PS1Pipeline`，内部场景 320×240，当前分辨率组合输出限制为 960px 宽以减轻填充负担。蓝血固定 `setMyopia(0)` / `setSquint(0)`，无近视机制。
- 镜中手机画面是同一 Three.js 场景的一台受限反向相机，低分辨率渲染后左右翻转；没有通过模型轮廓显示隐藏身份。
- 无恐惧值、伤害、好感或伪装数值。错误试卷仍是可擦除草稿，不产生被捕/死亡支线。
- `world.ts` 只建景；`main.ts` 管视角、碰撞、任务门控、对话、手机视角、血色和昼夜事件；`style.css` 保持中文界面可读。
- 浏览器开发模式提供 `window.__blueBloodTest`：snapshot 只读，moveToTask 仅便于放置视角且仍检查碰撞，interact 仍走实际交互条件。无跳章、修改故事标记或直接结束接口；生产不暴露此全局。

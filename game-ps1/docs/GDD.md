## 0. 现行首章规格

所谓“完整剧情”只指完整走到原文开放片段的第 113 行：车祸后在大楼外入场 → 走近红姐、俊哥问死亡/9999 分复活传闻/99 与 100 惊悚值规则 → 低层被选走而被送到 30 层 → 在 30F 走廊辨认冷意/血腥气、红墙与昏光 → 走到家门拍门 → 门边小孩 → 换衣擦脸哄睡 → 30→20 播报与贴近手机读群消息 → 家务 → 午睡惊醒 → 来人首次叫出“思思” → 思思被挥向阳台 → 女主起身斥责 → 玩家选择自己的立场。

- 主角看不到直播弹幕，不能把 30 层 Boss 强度或弹幕解释发给玩家；群消息是她实际贴近手机读到的三楼、十楼和惊悚值转述。
- 小孩在来人开口前不能在 UI 中叫“思思”。
- 高潮固定顺序为：思思维护（仍保留“留着好好玩”的复杂性）→ 来人不回应、挥手 → NPC 真正撞玻璃时 emit `sisiThrown` → glass/thud/shake/程序碎片 → `boss.confront` → 来人否认父女称呼 → 女主必然先起身斥责。
- 手机现在是必做主线，`<0.6m` 才可读；字幕和交互由 `runStoryAction` 串行，剧情原子段中的 E 只跳过当前字幕。
- 三个结尾是 `chapterProtect`、`chapterCalm`、`chapterDistance` 的**首章记录**，仅记玩家的动作与语气；不得补写来人/思思反应、伤势、关系真相或七日结局。`dead` 是独立的互动玩法失败页。
- 不眯眼的主线基础值为 40；维护/缓和/暂退后为 50/45/55。眯眼看恐怖目标仍是 +3/秒风险，不再生成原文之外的隐藏结局。
- 零外部素材仍成立：空间、NPC、玻璃碎片、音效和低分辨率墙/门纹理均运行时程序化生成。
- **开场空间已定**：主角出生在大楼外；走近红姐、俊哥问清规则，低层分配结束后转场抵达 30F。玩家要先在走廊靠近辨认冷意/血腥气、红墙与昏光，再走到自家门口拍门；门扇向屋内打开，不扫过走廊中的玩家。走廊中的升降设备仅是无文字场景陈设，不作为原文事实叙述。
- **高度近视焦距**：约 1 米内维持贴脸可辨；越过 1 米就进入更重的雾与失焦，2–3 米外仅能辨轮廓。思思在打开的门内约 2.65 米处以无五官红裙/双辫剪影停留，随后扑入走廊；门口一拍后她在玩家身侧的地面同行，不贴在镜头正前方，也不改变模型尺度。Q/右键眯眼可短暂看清，但直视真身会加惊悚。

## 1. 概念

### 一句话卖点

**PS1 低清画质不是情怀，是女主的近视度数——在这个恐怖副本里，「看不清」是保命天赋，「眯一眼看清真相」要用命付费。**

### 体验支柱（3 条）

1. **近视即渲染**：约 1 米内的贴脸细节仍可辨；越过这个焦距，PS1 低分辨率 + 浓雾 + 低模轮廓迅速把 2–3 米外化成轮廓。玩家看到的模糊世界 = 女主看到的模糊世界，零教学成本；墙体与纹理在移动中仍保持稳定。
2. **温情 × 恐怖的反差趣味**：给女儿换血裙→白裙、热毛巾擦脸、哄午睡、拖地铲墙——最家常的动作配最阴森的原料。恐怖感不由 Jump scare 承担，由「玩家眯眼看清原料是什么」承担。
3. **看清的代价，玩家自选**：眯眼（右键/Q）换取清晰与信息，但凝视恐怖真身会涨惊悚值，100 即死。每个玩家自己权衡「看清世界」还是「保持幸福」——两条路都有专属结局。

### 内容边界

- 故事止于 Boss 对峙抉择（原文第 113 行截断处）。**不编造**对峙之后任何剧情。
- 不搬原作 4–9 行预告内容（断头装回、一米八六、腹肌桥段）作为当下演出。
- 主角**看不到直播弹幕**（原文 29/44/72 行）：游戏无弹幕系统，只借弹幕体口吻写系统提示语。
- 女主形象：大大咧咧、贫嘴、莽、渴望家庭。恐怖在她嘴里永远变味成生活琐事。

## 3. 任务链详设（gameplay 状态机）

通用规则：
- 所有交互走 `Interactable`；顺序门控一律用 `available`（不满足时**不显示** prompt）。
- 台词用 `g.say(speaker, text)`，speaker：`我`（女主白）、`思思`（粉）、`???`（Boss 暗红）；系统用 `g.sys`（前置 `bell`）。
- 每句字幕可点击/E 跳过；事件总线约定：`'nap'` 睡觉完成、`'bossHome'` Boss 到场、`'sisiThrown'` 思思撞玻璃（由 npcs 在撞击瞬间 emit，gameplay 监听播 glass/thud）。

### 阶段 0 · 楼前入场、问规则与 30F 拍门

- `start()` 自动：黑屏 1s → `sys`：`【欢迎进入「幸福之家」副本】/【玩家在该副本存活七天，即为通关】/【初始玩家：30 人；现存活：30 人】/【祝各位玩家游戏愉快~】` → `flashWhite(300)` 睁眼（spawn 点在**大楼外**，冷雾吞掉远处轮廓）。
- 玩家走近红姐、俊哥，问到死亡、积分、惊悚值与一梯一户规则；低楼层被先到者选走，主角没有跟上人群，转场抵达 30F。主角不读取或转述直播弹幕。
- 抵达 30F 后，先在走廊以近距离交互辨认冷意/血腥气、红墙和昏光；两项近处观察完成，才解锁走到自家门口的 `door` 锚点交互「拍门」。
- 内心：`「不就是死了一次吗，多大点事。就是这配套视力，还是熟悉的配方。」`
- `doorCreak` → **门扇动画向屋内开** → 凉气与轻震 → **+5**。拍门台词：`「快开门啊，宝宝我回家啦！再不开门我要饿死了！」` 门开后：`「嚯，自带冷气，这房子血赚。」`

### 阶段 1 · 门口初见思思

- 门开后自动：sisi `setState('lunge')` 先在**门内**约 2.65m 处以无五官红影/双辫轮廓停留，再穿过门槛扑入 30F 走廊 → `sting` + `shake(0.6, 300)` → 两句贫嘴中掐脖渐松 → `setState('held')` → **+10**。`held` 不是贴脸悬空：她保持同一模型尺度，在玩家左侧地面随行；过门后继续同行进入照料链。
- 台词：`「小孩子怎么能穿湿衣服呢？快脱下！我带你去换干净衣服！」` `「你是不是哪里受伤了？药箱在哪？我帮你处理。」` 内心：`「怎么有股铁锈味……不重要，先换衣服。」`

### 阶段 2 · 照料链（顺序锁定：换裙 → 擦脸 → 哄睡）

① 换白裙：`bathroomCabinet`「翻衣柜」→ 获得白裙 → `kidsBed`「给她换白裙」（`available: hasDress`）→ sisi 红裙换白裙 `setState('changed')`。
② 擦脸：`bathroomCabinet`「拿热毛巾」（`available: sisi.state==='changed'`）→ sisi 本体「帮她擦脸」→ 血污淡出 `setState('clean')` + `kiss` → **−10**。
   台词：`「身为家人，互帮互助是我该做的。不过，你是不是得亲我一口，以表感谢？」` 思思：`「谢谢妈妈。」` 内心：`「啥？妈妈？俺无痛当妈啦！这简直是泰裤辣！」`
③ 哄午睡：`kidsBed`「哄她午睡」（`available: sisi.state==='clean'`）→ `setState('nap')` → `sys`：`【初始玩家：30 人；现存活：20 人】` → **进入阶段 3**。

### 阶段 3 · 手机（可选支线）与家务

- 手机：sofa 上 phone 呼吸光。交互要求相机距 phone **<0.6m**，否则 toast `「太模糊了，凑近点看。」`（不推进）。读时大字消息界面（玩家群聊体：黄毛被狗头吞、白骨、惊悚值 50、10 楼大叔 100、红姐压 60），读完 **+5**。台词：`「选个房就少了十个，这副本不讲武德。」`「这些都跟我无关。我家思思可爱着呢。」
- 家务：`mop`「拿起拖把」→ `floorArea` 拖地分 3 段（`floorArea.userData.floorMat` 血红→灰白 lerp，隐藏 `bloodDecals`）→ `wallStain1/2`「铲掉墙渍」（E×3，`thud`+碎屑，第 3 下血渍 `userData.mesh` 消失）。

### 阶段 4 · 午睡与惊醒

- sofa「眯一会」：渐黑 2s（`emit('nap')`）→ 黑屏 3s → 睁眼全屋灯光转暗、`setMyopia(0.55)` → **+10**。台词：`「怎么一觉醒来更瞎了……不对，是房子更黑了。」`

### 阶段 5 · Boss 回家

- 玩家回到客厅可见 door 区域（或 20s 超时强制）：`boss.setState('arrive')` + `emit('bossHome')`。
- 台词链：???：`「呵，有趣，居然能在思思手里活到现在。」` 内心：`「这嗓子……低音炮成精。等等，重点不是这个。」` 思思（defend）：`「你最好别动她，这个妈妈有点意思，我要留着好好玩。」` → Boss 挥手 → sisi `setState('thrown')` → 撞 balconyGlass（npc 在撞击瞬间 emit `'sisiThrown'`；gameplay 监听播 `glass`+`thud`+`shake(1,400)`）→ **+20**。
- 我：`「思思——！」` 起身（原文末句）：`「谁允许你这样跟孩子说话的？哪有你这样当爸——」`

### 阶段 6 · 对峙抉择

`prompt` 三选一（1/2/3）：

| id | label | 惊悚值 |
|---|---|---|
| `support` | 「她是我女儿，轮不到你动手。」 | +10 |
| `soften` | 「先别动手，孩子还伤着呢。」 | +5 |
| `retreat` | 「……你们家的事，我先坐回沙发。」 | +15 |

Boss 回应：`「谁允许你跟我这样说话的？真把自己当我女儿了？」` 1.5s 静场后进结局结算。

### 阶段 7 · 结局

结算顺序：**dead**（任意时刻 ≥100）→ **peep**（见 §5，在对峙选项加分**之前**判定）→ **truth**（≤45）→ **haze**（其余）。

## 4. 惊悚值经济

| 事件 | 数值 | 呈现要求 |
|---|---|---|
| 门开白闪凉气 | +5 | 条跳动 + 飘字 +5 |
| 被思思掐脖 | +10 | `sting` 震屏 + 红脉冲 |
| 被思思亲 | −10 | 条变绿 + 飘 −10 + `kiss` |
| 读完手机群消息（可选） | +5 | 读完后结算，可预期 |
| 家务 | 0 | 喘息段，不涨不降 |
| 惊醒房子暗沉 | +10 | 与 myopia 0.35→0.55 同步 |
| Boss 回家思思被撞 | +20 | 全剧最大单跳，glass+thud+震屏 |
| 对峙 维护/缓和/暂退 | +10/+5/+15 | 立场越怂越怕 |
| 恐怖凝视（眯眼看真身） | +3/秒 | 连续小步进，红脉冲 |

原则：**涨要可见**（条动画+飘字+≥70 红脉冲心跳+越线 sting）；**降要奖励**（绿飘字+正音效）。`fear>=100` 任意时刻立即 `end('dead')`。

路线核算（零凝视）：不读手机 = 5+10−10+10+20 = **35** → 维护 45 / 缓和 40 / 暂退 50；读手机 +5。

## 5. 眯眼机制

| 状态 | 触发 | myopia 参数 |
|---|---|---|
| 日常（前半场） | 默认 | 0.35 |
| 日常（惊醒后） | 阶段 4 起 | 0.55 |
| 眯眼 | 按住右键/Q（触屏双指） | 0（清晰+暗角收窄） |
| 松开 | 放开 | 回日常值 |

恐怖凝视（gameplay 每帧）：`input.squint > 0.5` 时，对真身目标（Boss 可见时、`sisi` 血裙态 lunge/held、wallStain 1.5m 内）做视野中心 ±10° 判定，命中 `fear.add(3*dt)` + 红脉冲；对思思的凝视秒数累计进 peep 计数（无 UI）。眯眼/松开的 `squintOn/Off` 音效由引擎边沿播放，gameplay 只调 `ps1.setMyopia`。

## 6. 四个结局（完整文案）

结算优先级：`dead` ＞ `peep` ＞ `truth` ＞ `haze`。结局页：全屏底色随 tone（good 暖黑 / bad 血红 / secret 冷蓝）+ 大字标题 + 副文案 + 「再玩一次」（reload）。

### `truth` · good ·「全家福」（条件：惊悚值 ≤ 45）

> 你看清了断头缝线和白裙上的每一块血渍，还是蹲下来替她系好了裙摆。
> 恐惧没有消失——是你看清了全部真相之后，仍然选择当她的妈妈。

### `haze` · good ·「温馨假象」（条件：其余 <100）

> 三米开外，人畜不分；三米之内，她软软地喊你妈妈。
> 看不清有什么不好？幸福本来就是 320×240 的。

### `dead` · bad ·「死亡之家」（条件：惊悚值 ≥ 100 任意时刻）

> 惊悚值：100。
> 你终于看清了一切——用停止的心跳作为代价。
> 从明天起，30 层的墙里会多一副新骨架。地板拖得再干净，也盖不住。

### `peep` · secret ·「……你刚才，一直看得见？」

> 思思歪着头，第一次认真地看你。
> 「妈妈，你刚才……一直看得见？」
> 你张了张嘴，没敢回答。
> 原来从进门那一刻起，你就看得一清二楚——包括她裙子上每一块干涸的血。
>
> （达成条件：对峙前累计眯眼看血裙思思 >20 秒且活到对峙。凝视 +60 恐惧，零凝视剧本最低 35 → 对峙时 95，走钢丝达成。）

## 8. 失败与防卡死

1. 不眯眼可通关（全部必需交互不要求眯眼；手机靠物理凑近）。眯眼是风险自选，不是操作门槛。
2. 阶段门控走 `available`，不该出现的 prompt 不出现；闲置 90s 每阶段弹一次贫嘴提示（每阶段仅一次）。
3. 死亡无 QTE，`dead` 页 reload 重开；单局 15 分钟，不做存档。
4. 字幕/播报均可跳过；`prompt` 必选才能继续。
5. 整屋 <30k 面、320×240 内部渲染，目标 60fps（M 系 Mac）。

## 9. 视听方向
